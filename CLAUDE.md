# agentCV: start here

The operating manual for this folder is **AGENTS.md** (one manual for Claude, Codex and other agents).
Read AGENTS.md now, in full, and follow it for the rest of the session. Then read `profile/house-rules.md`,
which wins over AGENTS.md where they conflict (except the safety rules).

**If AGENTS.md is missing** (an update from 0.9.2 or earlier adds it in a second pass): run
`python3 scripts/update.py apply` once more, then read AGENTS.md. Until then, `backups/` holds the previous full manual.

Don't put the user's rules in this file or in AGENTS.md: both are replaced when agentCV updates.
